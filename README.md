# Knightbot-MD (Baileys Pairing Edition)

بوت تيليجرام لربط أرقام **WhatsApp الشخصية** عبر **كود اقتران** من 8 خانات باستخدام مكتبة `@whiskeysockets/baileys` — لا حاجة لمسح QR من سطح المكتب.

## المزايا

- `/start` بواجهة شفافة بأزرار: **🔗 ربط رقم** · **🗑️ حذف جلسة** · **📱 أرقامي المربوطة** · **❓ المساعدة**.
- ربط الرقم فقط بإرسال الرقم نفسه (مثال: `967771163825`) بدون `+` أو مسافات.
- توليد كود اقتران مكوّن من 8 خانات منسّق `XXXX-XXXX` وعرضه للمستخدم.
- بمجرد تأكيد الربط من تطبيق واتساب، يتم الاتصال تلقائياً ويُفعّل التفاعل التلقائي مع **الحالات** (Status).
- أوامر: `/mynumbers`, `/deletesession`, `/setemoji`, `/autoreact`.
- تخزين جلسة Baileys محلياً داخل مجلد `data/sessions/<chatId>` لكل مستخدم تيليجرام.

## التشغيل

1. ثبّت الاعتمادات:
   ```bash
   npm install
   ```
2. أنشئ ملف `.env` انسخ فيه ما يلي:
   ```
   TELEGRAM_BOT_TOKEN=توكن_بوت_تيليجرام_هنا
   PORT=3000
   ```
3. شغّل البوت:
   ```bash
   npm start
   ```

## الاستخدام

- افتح البوت في تيليجرام ثم أرسل `/start`.
- اضغط **🔗 ربط رقم واتساب**، ثم أرسل الرقم الدولي بدون `+` (مثال: `967771163825`).
- سيُرسل لك الكود المنسَّق، افتح واتساب > الإعدادات > الأجهزة > **ربط جهاز** > اختر **ربط بالرقم** وأدخل الكود.
- بمجرد التأكيد من واتساب، يصلك إشعار «تم الربط بنجاح» تلقائياً ويبدأ التفاعل على الحالات.

## ملاحظات

- تم استخدام Baileys v7 لإنشاء اتصال WhatsApp Web، ثم `sock.requestPairingCode(phone)` يولّد الكود. تنظيف الرقم (إبقاء الأرقام فقط) يتم قبل الإرسال لأن Baileys يقبل أرقاماً فقط.
- الكود المولَّد من قبل واتساب نفسه عبر Baileys — البوت لا يصنع الكود محلياً، فقط ينسّقه ويعرضه.
- تم اختبار البناء عبر فحص الصياغة (`node -c`)، لكن لم يتم اختبار الربط على جهاز حقيقي في هذه الجلسة (لا اتصال Meta/واتساب متاح من داخل الساندبوكس).
